# Sayumi

Локальное рабочее пространство: аватар на экране, чат, заметки, задачи и файлы.
Чёрный фон, приглушённое золото, всё настраивается. Данные хранятся только на вашем
компьютере — ничего не уходит наружу без вашего ключа.

---

## Быстрый старт

Двойной клик по **`Sayumi.bat`** — и всё.

Ничего спрашивать не будет: лаунчер сам определит носитель и папку данных, найдёт Python
(а если его нет — скачает переносимую версию в папку проекта), поднимет локальный сервер
и **сам откроет сайт в браузере**. Своё окно закроет тоже само, сервер останется работать
в фоне.

В первые 3 секунды можно нажать **`M`** — тогда вместо автозапуска откроется меню:

```
  1  Запустить Sayumi
  2  Выбрать диск
  3  Выбрать папку данных
  4  Python: проверка и установка
  5  Настройки запуска
  6  Развернуть копию на диск или флешку
  7  Диагностика
  8  Язык / Language
  0  Выход
```

Повторный двойной клик, когда Sayumi уже запущена, не поднимает второй сервер — просто
открывает вкладку с уже работающим.

### Аргументы командной строки

```bat
Sayumi.bat           :: всё автоматически, сайт открывается сам
Sayumi.bat /menu     :: сразу меню, без автозапуска
Sayumi.bat /run      :: то же, что без аргументов
Sayumi.bat /setup    :: экран установки Python
Sayumi.bat /help     :: справка
```

## Что умеет лаунчер

| Возможность | Подробности |
| --- | --- |
| **Выбор диска** | Список всех дисков с типом (съёмный, локальный, сетевой, оптический), меткой и свободным местом. Данные переносятся в `X:\Sayumi\data`. |
| **Выбор папки** | Через проводник Windows, вводом пути вручную, рядом с программой или в «Документах». Проверяет права на запись. |
| **Работа с флешки** | Съёмный носитель определяется автоматически, включается переносимый режим: данные остаются на флешке, в системе ничего не прописывается. Файл `portable.flag` включает режим принудительно. |
| **Поиск Python** | Сохранённый путь → переносимый в проекте → `py -3` → `PATH` (заглушка из магазина пропускается) → реестр → типовые каталоги. |
| **Установка Python** | Если не найден: при автозапуске сразу ставится переносимый embeddable-архив в `runtime\python` (без прав администратора, подходит для флешки). В меню можно выбрать и обычный установщик в систему. Загрузка по HTTPS через PowerShell с проверкой результата и подписи Python. Предыдущая переносимая версия сохраняется как резервная копия. |
| **Русский без проблем** | Кодовая страница переключается на UTF-8 первой строкой; весь код батника — латиница, кириллица только в текстах. Если консоль не поддерживает UTF-8, лаунчер сам переходит на английский. Пункт `8` переключает язык вручную. |
| **Развёртывание копии** | Пункт `6` копирует проект на другой диск или флешку и помечает копию как переносимую. |
| **Окно без рамки браузера** | По умолчанию сайт открывается как отдельное приложение: без адресной строки, вкладок и закладок. Используется Chrome, Edge, Brave или Chromium — что найдётся. Переключается в «Настройках запуска», пункт «Режим окна». |
| **Диагностика** | Архитектура, пути, версия PowerShell, найденный Python, ответ сервера и расположение журналов. |

Настройки запуска хранятся в `Sayumi.config.json` рядом с батником. Старый
`Sayumi.config.cmd` читается как набор значений и не выполняется.

### Если Python не находится совсем

При автозапуске лаунчер сам попробует поставить переносимую версию. Если и это не вышло
(например, нет интернета), он покажет ошибку. Интерфейс можно открыть вручную из `web/index.html`. Чат, заметки, задачи, оформление и
настройки продолжат работать — не будет только рабочей папки с файлами и обхода CORS
для внешних API.

## Интерфейс

### Аватар

* **Левая кнопка** — открывает чат.
* **Правая кнопка** — открывает её настройки.
* **Перетаскивание** — мышкой в любое место экрана, позиция запоминается и переживает
  изменение размера окна.
* **Колесо мыши над ней** — меняет размер на лету.
* **Shift + клик** — тоже открывает настройки.
* **Живая анимация** — дыхание и лёгкое покачивание, сила регулируется.
* **Моргание** — работает, если загрузить второй кадр с закрытыми глазами.
* **Уходит, пока вы печатаете** — становится почти прозрачной и не мешает читать.
* **Золотая пыль** — редкие медленные искры поднимаются вокруг неё.

### Чат

Полноценный рабочий инструмент, а не просто окно сообщений:

* несколько диалогов с закреплением, переименованием, дублированием и поиском;
* markdown с таблицами, цитатами, списками и подсветкой кода, кнопка «копировать» у каждого блока;
* потоковый ответ, кнопка «Стоп»;
* ветвление: перегенерация не стирает прежний ответ, а кладёт его рядом как вариант,
  между вариантами можно ходить стрелками, в контекст идёт только выбранный;
* вложения: скрепка или перетаскивание файлов прямо в окно, текстовые файлы читаются целиком;
* действия над сообщением: копировать, изменить, отправить заново, перегенерировать, озвучить, удалить;
* голосовой ввод и озвучивание ответов;
* шаблоны запросов, свои сохраняются прямо из поля ввода;
* поиск по диалогу, экспорт в `md` / `txt` / `json`, импорт из `json`;
* счётчик контекста в токенах;
* команды: `/help`, `/new`, `/clear`, `/rename`, `/model`, `/system`, `/temp`, `/export`,
  `/theme`, `/lang`, `/tts`, `/notes`, `/tasks`, `/files`, `/graph`, `/memory`,
  `/code`, `/find`, `/persona`, `/settings`, `/stop`.

**Подключение модели** — чип в шапке чата или вкладка «Модель» в настройках проекта:

| Провайдер | Примечание |
| --- | --- |
| Автономно | Без модели. Арифметика, дата, id, работа с заметками и файлами. |
| **Cloud.ru Foundation Models** | Адрес по умолчанию `https://foundation-models.api.cloud.ru/v1`. |
| OpenAI-совместимый | OpenAI, LM Studio, vLLM, groq и любой совместимый endpoint. |
| Anthropic | Claude. |
| Ollama | Локальные модели, по умолчанию `http://127.0.0.1:11434`. |

### Подключение Cloud.ru

1. Запустите `Sayumi.bat` — для внешних API нужен локальный сервер, иначе браузер
   заблокирует запрос по CORS.
2. Шестерёнка → **Модель** → провайдер **Cloud.ru Foundation Models**.
3. Вставьте ключ из личного кабинета Cloud.ru, сервис Foundation Models.
   Адрес API можно оставить пустым — подставится стандартный.
4. Нажмите кнопку обновления рядом с полем «Модель» — список подтянется прямо из
   вашего аккаунта, со всеми доступными моделями.
5. Выберите модель и нажмите **Проверить соединение**.

Ключ хранится только в вашем браузере и уходит исключительно на локальный сервер,
который передаёт его в Cloud.ru. Кнопка «Стереть ключ» убирает его полностью.
Идентификаторы моделей сохраняются целиком, вместе со слешем — например
`deepseek-ai/DeepSeek-V3`.

Когда запущен локальный сервер, запросы идут через него — ключ не светится в браузере и
не мешает CORS. Без сервера браузер пробует обратиться к API напрямую.

### Память и саморазвитие

Она помнит между запусками и накапливает опыт. Память открывается командой `/memory`,
сегментом в строке состояния или сочетанием `Ctrl + M`.

**Запоминает сама.** Из обычной речи вылавливает имена, привычки, правила, решения и
используемые технологии: «меня зовут Алексей», «я пишу на Python», «никогда не предлагай
сторонние библиотеки». Прямая команда — `запомни: ...` — кладёт запись с высоким весом и
закрепляет навсегда. Когда подключена модель, раз в несколько реплик она дополнительно
просит её вытащить из диалога то, что правила пропустили.

**Вспоминает к месту.** Перед каждым запросом из памяти выбирается самое подходящее и
подмешивается в системный промпт, в пределах бюджета токенов. Поиск — BM25 по основам
слов (алгоритм Портера для русского) с учётом свежести, веса и частоты использования.
Если по ключевым словам ничего не нашлось, добирает самые важные записи, чтобы
закреплённое было перед глазами всегда.

**Ищет по смыслу.** Если указать модель эмбеддингов, записи векторизуются и подбираются
по близости смысла, а не по совпадению слов: «на чём я программирую» найдёт «пишет на
Python». Векторный и словесный поиск складываются, промах одного закрывает другой.

**Осмысливает накопленное.** Раз в N ответов, или по кнопке, перечитывает свою память:
объединяет повторы, убирает устаревшее и противоречивое, записывает новый вывод.
Закреплённое не трогает никогда.

**Показывает, что знает.** Карта связей — записи как узлы, цвет по виду, связь там, где
общие слова. Хроника — что и когда узнала, с ползунком «память на дату».

**Забывает слабое.** Предел 600 записей; при переполнении уходят наименее полезные,
закреплённые остаются навсегда. Похожие записи не плодятся, а усиливают друг друга.

**Подстраивается.** «отвечай короче», «давай на ты», «без шуток» — и ползунки характера
сдвигаются сами. Каждое изменение записывается в журнал с причиной, всё можно откатить
одной кнопкой.

**Растёт.** Опыт и уровень копятся от общения и работы. На вкладке «Развитие» видно, о чём
вы чаще говорите, в какое время работаете, какие команды любите, сколько знакомы и что
она поменяла в себе.

Всё лежит только на вашем компьютере, выгружается и загружается одним файлом, стирается
одной кнопкой.

### Связи и сквозной поиск

Задачи, заметки, чаты и память — одно целое, а не четыре отдельных списка.

Любое сообщение, задачу, заметку или запись памяти можно отправить в любое другое место:
из ответа в чате сделать задачу, из задачи — заметку, из заметки — запись в память. Связь
записывается в обе стороны и показывается полоской «связано» прямо на карточке; клик по
ней открывает то, что на другом конце, и подсвечивает его. Крестик связь убирает. Ссылки
на удалённое подчищаются при запуске.

**Поиск по всему** — `Ctrl + K`, кнопка с лупой в шапке или команда `/find текст`. Один
запрос идёт по чатам и каждому сообщению, заметкам, задачам, памяти и прочитанным файлам
проекта. Ищет по основам слов, поэтому «стеммера» находит «стеммер». Стрелки выбирают,
Enter открывает нужное окно на нужном месте.

### Чтение проекта

Она может отвечать по вашим файлам, а не по догадкам. Рабочая папка читается, режется на
перекрывающиеся фрагменты и индексируется; подходящие куски подмешиваются в вопрос со
ссылкой на файл и строку. Открывается командой `/code`. Там же видно, что прочитано, и
можно проверить поиск, не выходя из окна.

### Заметки, задачи, файлы

* **Заметки** — список с поиском, markdown-редактор с предпросмотром, выгрузка в `.md`.
  Заметки связываются между собой через `[[Название]]`: ссылка в предпросмотре кликабельна,
  несуществующая подсвечена пунктиром и создаётся по клику. Внизу показано, куда ведёт
  заметка и кто ссылается на неё. Кнопка графа открывает **граф связей**: дугообразные
  рёбра с бегущими по ним золотыми искрами, тени под узлами, подсветка соседей при
  наведении, разлёт узлов при открытии. Узлы таскаются, клик открывает заметку.
  Подписи скрываются только когда заметок действительно много.
* **Задачи** — доска из трёх колонок с перетаскиванием, или простой список.
  Карточки появляются лесенкой, подсвечиваются под курсором, при переносе наклоняются,
  а колонка-приёмник светится. Переехав в «Готово», задача вспыхивает и рассыпает искры.
  Карточки плавно переезжают на новые места, важное помечено живой полосой, просроченное
  пульсирует, под заголовком колонки идёт полоска её доли.
  Приоритет и срок можно задать прямо в строке: `сдать отчёт !важно 2026-11-20`.
  Просроченное и близкое подсвечивается, о сроках она напоминает сама, не чаще раза в
  день на задачу. Кнопка «→» отправляет задачу в чат.
* **Файлы** — рабочая папка `data/workspace`: просмотр, правка и сохранение текстовых
  файлов, отправка содержимого в чат. Требует запущенного сервера.

### Уведомления

На аватаре появляется значок с числом непрочитанного: подошедшие сроки, просроченное,
то что она запомнила или осмыслила сама, ответ, пришедший с закрытым чатом. Просрочка
красит значок тревожным. Клик по значку открывает панель рядом с ней — чат при этом не
открывается; клик по строке ведёт прямо к той задаче или тому чату, о котором речь.
Повторно об одном и том же за день она не напоминает.

### Строка состояния

Внизу окна — узкая полоса: адрес локального сервера с живым индикатором, подключённая
модель, объём текущего диалога в сообщениях и токенах, число заметок и незакрытых задач,
текущее оформление и часы. Клик по сегментам открывает проверку сервера, настройки
модели, чат и задачи.

### Настройки проекта (шестерёнка)

Разделы вынесены в боковое меню слева, каждая группа настроек — отдельная карточка
с иконкой и подзаголовком.

* **Оформление** — наверху живой макет интерфейса, который меняется прямо при выборе.
  10 готовых сочетаний показаны крупными превью: миниатюра окна в цветах темы, а не
  полоска образцов. Дальше 6 фонов, 10 акцентов, текстура фона (виньетка, сетка, лучи,
  зерно), плотность, размер шрифта, свечение, анимации.
* **Шрифты** — отдельно заголовочный, интерфейсный и моноширинный, с образцом текста.
  В списке показаны только те, что реально установлены в системе.
* **Рамки и тени** — скругление углов, толщина рамок и глубина тени тремя ползунками.

Все подтверждения и вводы — собственные окна проекта, а не системные окна браузера.
На узком экране раскладка перестраивается: окна разворачиваются во весь экран, боковые
панели наезжают поверх, рейки разделов превращаются в прокручиваемый ряд.

Иконки по всему интерфейсу — единый штриховой набор на сетке 16×16, наследующий цвет
акцента. Все отступы выровнены по сетке 4 px. Крупные надписи — заголовок, название в
шапке, имена окон и секций — набраны засечным шрифтом. Тени окон, меню и уведомлений
подкрашены акцентом, а не просто чёрные. Под шапкой проходит золотая линия с
медленным переливом, цитаты в сообщениях оформлены золотой полосой с кавычкой.
* **Интерфейс** — язык, поведение Enter, время сообщений, аватар, размер окон, сброс
  положения, горячие клавиши.
* **Модель** — провайдер, ключ, температура, лимит токенов, глубина контекста, проверка соединения.
* **Данные** — состояние сервера, резервная копия всего в один файл, восстановление, размер хранилища, сброс.
* **О проекте** — версия, режим запуска, справка по командам.

Правый клик по шестерёнке — быстрое меню: следующий фон, следующий акцент, следующее сочетание.

### Настройки Sayumi (правый клик по аватару)

* **Характер** — имя, роль, обращение, приветствие, ползунки теплоты, формальности, юмора и подробности.
* **Голос** — выбор голоса синтеза речи, скорость, высота, проверка.
* **Внешний вид** — своё изображение, размер, прозрачность, свечение, скрытие, прилипание к краю.
* **Память** — короткие факты, которые добавляются к каждому запросу.
* **Промпт** — готовый системный промпт целиком плюс поле для своих дополнений.

### Размер окон

Окна занимают долю экрана, а не фиксированное число точек: на широком мониторе они
широкие, на ноутбуке помещаются целиком. Общий регулятор в «Интерфейс → Окна»:
компактно, обычно, просторно или почти во весь экран. Кнопка «Разложить заново»
применяет выбранное ко всем открытым окнам. Размер каждого окна запоминается отдельно,
как только вы его потянете.

Широкое окно раскладывает карточки настроек и памяти в две колонки, боковые панели со
списком чатов и заметок растут вместе с окном, а карта памяти занимает всю оставшуюся
высоту, а не упирается в фиксированные 420 точек.

## Тесты

```bash
node tests/run.js
```

Два набора. Модульный загружает настоящие файлы интерфейса в песочницу и проверяет
разметку, стеммер, поиск по памяти, миграции и хранилище. Браузерный поднимает сервер и
подставной провайдер модели, затем проходит Chromium по реальным сценариям: аватар, чат,
диалоги, память, заметки, граф, доска задач, ветвление, чтение проекта, настройки и
компактная раскладка. Любая ошибка в консоли за весь прогон роняет набор.

## Обновление данных

Формат хранения пронумерован. При запуске выполняются только недостающие шаги, перед
этим снимается резервная копия. Данные, записанные более новой версией, не трогаются.

## Требования

* Windows 10 и новее, Windows PowerShell 5.1+ для `Sayumi.bat`.
* Python 3.8+ для сервера — лаунчер поставит сам, если его нет.
* Любой современный браузер. Голосовой ввод работает в Chrome и Edge.

Сервер слушает только `127.0.0.1` и не виден из сети.

### Надёжный запуск и перенос

`Sayumi.bat` запускает `tools/launcher.ps1`. Для запуска сервера требуется Python 3.8+
с модулями стандартной библиотеки; pip не устанавливается. Автоустановка использует Python 3.12.7.
Браузер открывается только после проверки `/api/health`, включая папки программы и данных.
Сервер получает фиксированный порт; ошибки записываются в `logs/*.err.log`.

Перед сменой папки данных или развёртыванием остановите сервер. Выбирайте новую,
ещё не существующую или пустую папку назначения. Файлы копируются с проверкой SHA-256;
исходная папка сохраняется как резервная копия. Настройка переключается после успешного копирования.
Вложенные пути, ссылки и перезапись непустых папок запрещены.

Развёртывание копирует приложение, выбранные данные и активный переносимый Python,
если он установлен. Конфигурация с абсолютными путями, журналы и кеши не копируются.
На новом компьютере при отсутствии переносимого Python потребуется его установка.

Проверки логики лаунчера: `powershell -NoProfile -File tests/launcher.ps1`.
Полная проверка окон, установки Python и запуска браузера выполняется на Windows.
